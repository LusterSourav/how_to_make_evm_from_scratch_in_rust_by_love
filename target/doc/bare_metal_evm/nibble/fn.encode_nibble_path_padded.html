pub fn encode_nibble_path_padded(path: &[Nibble]) -> NibblePathPacked
Expand description

Encode a nibble path into bytes, applying HP byte-alignment padding.

If the path has an even number of nibbles, a 0x00 padding nibble is prepended so that the resulting sequence is byte-aligned. This is the first step of Hex-Prefix (HP) encoding (the actual HP flags are added at a higher level).

Returns a NibblePathPacked with at most MAX_PACKED_BYTES bytes.

§Panics

Panics if the path is longer than 64 nibbles (the maximum for a 32-byte hash, which is the longest key in the MPT).
