pub fn abs(&self) -> Self

Two’s complement absolute value.

For INT256_MIN (0x8000…0000) this returns INT256_MIN since its positive value does not fit in 256 bits. Callers performing signed arithmetic should handle this case at the SDIV/SMOD level.
